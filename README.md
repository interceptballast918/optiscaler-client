## Under the hood

This tool uses specialized libraries to inject logic into your game files. It intercepts rendering calls from the game engine. Instead of drawing the frame at your native resolution, it draws at a lower resolution. The software then uses machine learning to upscale the image to match your monitor resolution. This saves a massive amount of processing power.

The software also implements frame generation. This tech inserts synthetic frames calculated by your graphics card. This makes movement appear smoother to your eye. The process happens in real-time.
